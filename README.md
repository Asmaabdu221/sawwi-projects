## المتطلبات — واحد فقط

```bash
node --version     # يلزم 20 أو أحدث
```

هذا كل شيء. حمّل أي مشروع وشغّله — **بلا حساب ولا اشتراك ولا مفتاح**.

### المحرّكات — اختر ما يناسبك

مشاريعنا تعمل بثلاثة محرّكات وتختار المتاح تلقائيًا، فلا تعلق أبدًا:

| المحرّك | التكلفة | بياناتك | متى تختاره |
|---|---|---|---|
| **قواعد** | **مجاني** | لا تغادر جهازك | تريد نتيجة الآن بلا أي إعداد |
| **نموذج محلي** ([Ollama](https://ollama.com/download)) | **مجاني** | لا تغادر جهازك | تريد ذكاءً حقيقيًا وخصوصية تامة |
| **Claude** | اشتراك مدفوع | تُرسل إلى Claude | تريد أعلى دقة |

> **اشتراك Claude اختياري** — ومن أراده فهو Pro فأعلى؛ [الخطة المجانية لا تشمل Claude Code](https://code.claude.com/docs/en/setup). ولا مفتاح API ولا فاتورة ثانية فوق الاشتراك.

كل مشروع يذكر في دليله دقة كل محرّك **مقيسةً على بيانات لم يُضبط عليها**، لا موعودة.

## الخصوصية — اقرأها قبل أي مشروع

هذه المشاريع ترسل ما تعطيها إلى Claude، تمامًا كما لو لصقته في المحادثة بنفسك.

**قبل استخدام أي مشروع على بيانات عمل حقيقية:**
- جرّبه على بيانات المثال المرفقة أولًا
- راجع سياسة شركتك في مشاركة البيانات
- خذ موافقة إدارتك

كل مشروع يذكر في دليله ما يرسله وما لا يرسله.
