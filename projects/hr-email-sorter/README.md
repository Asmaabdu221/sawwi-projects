# فارز بريد الموارد البشرية

**يقرأ رسائل بريد العمل، يصنّفها، ويقول لك أيّها يحتاج ردًا اليوم.**

من فيديو: [مئة رسالة HR مختلطة — الذكاء يفرزها قبل ما تفتح واحدة](#)

## وش يسوي

يأخذ ملف رسائل ويرجّع ملف Excel فيه لكل رسالة:

| العمود | المعنى |
|---|---|
| `category` | إجازة · توظيف · شكوى · استفسار · متابعة · أخرى |
| `urgent` | تحتاج ردًا خلال ٢٤ ساعة |
| `confidence` | ثقة التصنيف — «منخفضة» تعني راجعها بنفسك |
| `reason` | لماذا صُنّفت هكذا |
| `draft` | مسودة رد رسمية (اختياري) |

**الشكاوى لا تُكتب لها مسودات** — عمدًا. هذه مواضيع حساسة تُقرأ بعين إنسان.

## التشغيل — دقيقتان

### ١. المتطلبات
```bash
node --version          # يلزم 20 أو أحدث
npm install -g @anthropic-ai/claude-code
claude                  # سجّل الدخول باشتراكك مرة واحدة
```

> **لا تحتاج مفتاح API ولا بطاقة دفع.** يستخدم اشتراك Claude الذي عندك.

### ٢. جرّبه على بيانات المثال
```bash
node sort-emails.mjs
```
ثمان رسائل جاهزة في `sample-emails.csv` — يشتغل فورًا بلا أي إعداد.

### ٣. شغّله على بريدك
صدّر رسائلك إلى ملف CSV بثلاثة أعمدة:
```csv
from,subject,body
ahmed@company.sa,طلب إجازة,السلام عليكم، أرغب بإجازة من ١٠ إلى ١٧...
```
ثم:
```bash
node sort-emails.mjs my-emails.csv
```

### ٤. مع مسودات الردود
```bash
node sort-emails.mjs my-emails.csv --drafts
```

## عدّله ليناسبك

كل شيء في **`categories.json`** — ولا تحتاج تلمس الكود:

```json
{
  "categories": [
    { "key": "إجازة", "desc": "طلبات الإجازات والاستئذان", "reply": true }
  ],
  "urgentWords": ["طارئ", "عاجل", "فورًا"]
}
```

**أضف فئة:** سطر جديد في `categories`.
**غيّر ما يُعدّ عاجلًا:** عدّل `urgentWords`.
**اجعلها لقسم آخر:** استبدل الفئات كلها — الكود لا يعرف شيئًا عن الموارد البشرية، يقرأ فئاتك فقط.

## كيف تصدّر بريدك إلى CSV

<details>
<summary><b>Outlook</b></summary>

File ← Open & Export ← Import/Export ← Export to a file ← Comma Separated Values ← اختر المجلد ← احفظ.
ثم افتح الملف بـExcel واحتفظ بأعمدة `From` و`Subject` و`Body` فقط، وسمّها بالإنجليزي الصغير: `from,subject,body`.
</details>

<details>
<summary><b>Gmail</b></summary>

Gmail لا يصدّر CSV مباشرة. أسهل طريقة: افتح Google Sheets ← إضافة **Email Sheets** أو انسخ الرسائل يدويًا إلى جدول بثلاثة أعمدة ← File ← Download ← CSV.
</details>

## ما لا يفعله

- **لا يتصل ببريدك.** يقرأ ملفًا تعطيه إياه — لا صلاحيات ولا كلمات مرور.
- **لا يرد تلقائيًا.** يكتب مسودات فقط، وأنت ترسل.
- **لا يرسل بياناتك لأحد** غير Claude الذي تستخدمه أصلًا.

---

## الخصوصية

رسائلك تُرسل إلى Claude للتصنيف — تمامًا كما لو لصقتها في المحادثة بنفسك.
**لا تمرّر بيانات تخالف سياسة شركتك.** جرّبه على رسائل غير حساسة أولًا، وخذ موافقة إدارتك قبل استخدامه على بريد حقيقي.
