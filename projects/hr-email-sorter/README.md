# فارز بريد الموارد البشرية

**يقرأ رسائل بريد العمل، يصنّفها، ويقول لك أيّها يحتاج ردًا اليوم.**

من فيديو: [مئة رسالة HR مختلطة — الذكاء يفرزها قبل ما تفتح واحدة](#)

</div>

---

## التشغيل — أمر واحد، بلا حساب ولا اشتراك

```bash
node sort-emails.mjs
```

يشتغل فورًا على ثمان رسائل مثال. **لا يحتاج اشتراكًا ولا مفتاحًا ولا إنترنت** — يختار المحرّك المتاح على جهازك تلقائيًا.

> يلزمك [Node.js](https://nodejs.org) نسخة ٢٠ أو أحدث. لا شيء غير ذلك.

---

## المحرّكات الثلاثة

| المحرّك | التكلفة | بياناتك | السرعة | الدقة المقيسة |
|---|---|---|---|---|
| **`rules`** قواعد وكلمات | **مجاني** | **لا تغادر جهازك** | فوري | ٧ من ١٢ |
| **`ollama`** نموذج محلي | **مجاني** | **لا تغادر جهازك** | بطيء | ٩ من ١٢ |
| **`claude`** اشتراك Claude | اشتراك مدفوع | تُرسل إلى Claude | متوسط | **١٢ من ١٢** |

```bash
node sort-emails.mjs --engine rules      # مجاني وفوري
node sort-emails.mjs --engine ollama     # مجاني وذكي وخاص
node sort-emails.mjs --engine claude     # أدق
```

بلا خيار، يجرّب بالترتيب: `ollama` ← `claude` ← `rules`. فلا يفشل أبدًا.

---

## الدقة — أرقام مقيسة لا موعودة

اختبرنا المحرّكات على **١٢ رسالة سعودية واقعية لم يُضبط عليها أي محرّك**، فيها خمسة فخاخ مقصودة.

| | القواعد | نموذج محلي `qwen3:8b` | Claude |
|---|---|---|---|
| صحيحة | ٧ من ١٢ | ٩ من ١٢ | **١٢ من ١٢** |
| أخطاء **صامتة** (بثقة متوسطة فأعلى) | ٢ | **٠** | **٠** |
| الزمن | **أقل من ثانية** | ٣٣٦ ثانية | ٨٠ ثانية |
| التكلفة | **مجاني** | **مجاني** | اشتراك |

> النموذج المحلي أخطأ ثلاثًا لكنه **أعلن عن كل واحدة** بثقة منخفضة. القواعد أخطأت خمسًا ومرّرت اثنتين بلا تحذير. الخطأ المُعلَن أرخص من الخطأ الصامت — لذلك يستحق عمود «الأخطاء الصامتة» نظرك قبل عمود الدقة.

**أين تسقط القواعد بالضبط:**

| الرسالة | الصواب | القواعد | السبب |
|---|---|---|---|
| «نقاش ضروري» | شكوى | إجازة | «ال**وضع** ما عاد مريح» طابقت «وضع» |
| «عرض خدمات توظيف» | أخرى | توظيف | شركة تبيع خدمات، لا متقدّم |
| «كشف الرواتب» | أخرى | استفسار | إشعار لا سؤال |
| «بخصوص الأسبوع الجاي» | إجازة | أخرى | «ودي أغيب» بلا كلمة إجازة |
| «ما أقدر أكمل كذا» | شكوى | أخرى | شكوى بلا كلمة شكوى |

### تأكّد بنفسك

الاثنتا عشرة رسالة مرفقة مع المشروع، ومعها الجواب الصحيح لكل واحدة:

```bash
node benchmark.mjs rules                  # فوري
node benchmark.mjs rules ollama claude    # قارن الثلاثة
```

يطبع لك جدول المقارنة نفسه، ويوضّح أي خطأ **حذّر** عنه المحرّك وأيّها مرّ **صامتًا**. لا تصدّق أرقامنا — أعد إنتاجها.

**الخلاصة:** الكلمات المفتاحية تلتقط الصريح وتسقط في المبطّن. الذكاء يقرأ النية. استخدم القواعد للفرز السريع المجاني، والذكاء حين يهمّك ما بين السطور.

الاستعجال يُحسب بمطابقة الكلمات في كل المحرّكات — النماذج تسهو عنه، والمطابقة لا تسهو.

## المحرّك المحلي المجاني

```bash
# ثبّت Ollama مرة واحدة: https://ollama.com/download
ollama pull qwen3:4b       # ٢٫٥ جيجا — مرة واحدة
node sort-emails.mjs --engine ollama
```

بعدها كل شيء مجاني وبلا إنترنت، **ولا تخرج رسالة واحدة من جهازك**.
نموذج ٤–٨ مليار يحتاج ذاكرة ٨ جيجا فأكثر. على المعالج وحده بلا كرت رسوميات يأخذ نحو نصف دقيقة للرسالة — مجاني وخاص، لكنه ليس سريعًا.

لاختيار نموذج غير الافتراضي: `--model اسم-النموذج`

## محرّك Claude

```bash
irm https://claude.ai/install.ps1 | iex     # ويندوز
claude                                       # سجّل الدخول
node sort-emails.mjs --engine claude
```

> **يلزمه اشتراك Claude مدفوع** — Pro أو Max أو Team أو Enterprise.
> [خطة claude.ai المجانية لا تشمل Claude Code](https://code.claude.com/docs/en/setup) فلن يعمل هذا المحرّك معها.
> لا مفتاح API ولا فاتورة ثانية فوق اشتراكك.

وهو المحرّك الوحيد الذي يكتب **مسودات الردود**:
```bash
node sort-emails.mjs --drafts
```

## وش يطلع لك

ملف `sorted-emails.csv` جاهز لـExcel:

| العمود | المعنى |
|---|---|
| `category` | إجازة · توظيف · شكوى · استفسار · متابعة · أخرى |
| `urgent` | تحتاج ردًا خلال ٢٤ ساعة |
| `confidence` | ثقة التصنيف — **«منخفضة» تعني راجعها بنفسك** |
| `reason` | لماذا صُنّفت هكذا |
| `draft` | مسودة رد رسمية (مع `--drafts`) |

**الشكاوى لا تُكتب لها مسودات** — عمدًا. مواضيع حساسة تُقرأ بعين إنسان.

## شغّله على بريدك

### الطريقة الأولى: احفظ الرسائل وحوّلها — بلا Excel

احفظ الرسائل التي تريد فرزها من بريدك:

| بريدك | كيف تحفظ رسالة |
|---|---|
| **Gmail** | افتح الرسالة ← ⋮ ← **Download message** |
| **Outlook على المتصفح** | افتح الرسالة ← ⋯ ← **Download** |
| **Thunderbird** | حدّد الرسائل واسحبها إلى مجلد |

ضعها كلها في مجلد اسمه `emails` بجانب المشروع، ثم:

```bash
node eml-to-csv.mjs
node sort-emails.mjs my-emails.csv
```

يقرأ العربية من الترميزات التي تستخدمها عملاء البريد، وينظّف الاقتباسات وتوقيع الرد السابق.

### الطريقة الثانية: القالب الجاهز

افتح **`my-emails.csv`** بـExcel، امسح سطر المثال، والصق رسائلك في ثلاثة أعمدة:
```csv
from,subject,body
ahmed@company.sa,طلب إجازة,السلام عليكم، أرغب بإجازة من ١٠ إلى ١٧...
```
ثم احفظ بصيغة **`CSV UTF-8 (Comma delimited)`** — لا «CSV» وحدها، وإلا تحوّلت العربية رموزًا. المشروع يكشف هذا ويخبرك.

```bash
node sort-emails.mjs my-emails.csv
```

<details>
<summary><b>تصدير دفعة واحدة من Outlook المكتبي</b></summary>

File ← Open & Export ← Import/Export ← Export to a file ← Comma Separated Values ← اختر المجلد ← احفظ.
ثم افتح الملف بـExcel واحتفظ بأعمدة `From` و`Subject` و`Body` فقط، وسمّها بالإنجليزي الصغير: `from,subject,body`.
</details>

<details>
<summary><b>كيف تصدّر من Gmail</b></summary>

Gmail لا يصدّر CSV مباشرة. أسهل طريقة: افتح Google Sheets وانسخ الرسائل إلى جدول بثلاثة أعمدة ← File ← Download ← CSV.
</details>

## عدّله ليناسبك

كل شيء في **`categories.json`** — ولا تحتاج تلمس الكود:

```json
{
  "engine": "auto",
  "ollamaModel": "qwen3:4b",
  "categories": [
    { "key": "إجازة", "desc": "طلبات الإجازات والاستئذان",
      "reply": true, "words": ["إجازة", "استئذان", "مغادرة"] }
  ],
  "urgentWords": ["طارئ", "عاجل", "فورًا"]
}
```

| تريد | عدّل |
|---|---|
| فئة جديدة | أضف سطرًا في `categories` |
| دقة أعلى لمحرّك القواعد | أضف كلمات في `words` — هي ما يطابقه |
| ما يُعدّ عاجلًا | `urgentWords` |
| محرّكًا ثابتًا | `engine` |
| قسمًا غير الموارد البشرية | استبدل الفئات كلها — الكود لا يعرف شيئًا عن HR، يقرأ فئاتك فقط |

---

## ما لا يفعله

- **لا يتصل ببريدك.** يقرأ ملفًا تعطيه إياه — لا صلاحيات ولا كلمات مرور.
- **لا يرد تلقائيًا.** يكتب مسودات، وأنت ترسل.
- **لا يرسل شيئًا** في محرّكي `rules` و`ollama` — كل شيء على جهازك.

## الخصوصية

| المحرّك | ما يخرج من جهازك |
|---|---|
| `rules` | **لا شيء** |
| `ollama` | **لا شيء** |
| `claude` | نص الرسائل يُرسل إلى Claude — كما لو لصقته في المحادثة |

على بريد عمل حقيقي فيه شكاوى ورواتب: ابدأ بـ`rules` أو `ollama`. وقبل استخدام `claude` راجع سياسة شركتك في مشاركة البيانات وخذ موافقة إدارتك.
